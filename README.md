# 今日油价 ⛽

一个适配手机和电脑的全国油价查询与出行费用估算页面。

**在线访问**：https://liuyuhang888.github.io/today-oil-price/

- 自动定位或手动选择地区，查看当地 92 号和 95 号汽油参考价，并记住所选地区。
- 查看全国各油品均价、上次调价变化、价格排名及调价窗口。
- 按地区和油品查看年度历史走势，支持触摸、鼠标和键盘查看数据。
- 按品牌、年款和车型选择参考油耗，也可手动调整，计算旅程的油费和充电费用。
- 搜索各省油价，查看数据更新时间及过期提示。

历史记录和车型数据会随可用数据持续补充；部分车型需手动填写油耗。插混和增程车型的实际费用受充电方式、路况和驾驶习惯影响，计算结果仅供参考。

## 本地运行

```bash
python3 -m http.server 8000
```

在浏览器访问 `http://localhost:8000/`。
